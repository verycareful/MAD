01

Problem Statement

Standard gradient-based optimizers follow the steepest descent at every step. When they land in a local minimum, they stop — with no mechanism to determine whether a deeper minimum exists elsewhere in the landscape. Current escape strategies (noise injection, momentum, learning rate schedules) are blind: they run at all times as a precaution, without knowing whether the optimizer is stuck.

MAD addresses this by treating the loss landscape as a traversable topology. It uses structured ascent — climbing out via the shallowest available path — to systematically discover and compare all reachable local minima, returning the global minimum upon exhaustion of the landscape.

02

Setup & Definitions

Given: A differentiable loss function \( f : \mathbb{R}^d \rightarrow \mathbb{R} \) over a finite landscape.

Definitions

\( \mathcal{V} = \{\theta^*_1, \theta^*_2, \ldots\} \) — set of visited local minima. Initially empty.
\( \theta^*_{\text{best}} \) — running best minimum. Updated whenever a new minimum with lower loss is found.
\( \mathcal{P} \) — stack of active pass points. Each pass point stores its position and a priority queue of candidate descent directions.
\( D(\mathcal{V}, \theta_n) \) — dynamic exclusion set. The set of unit vectors pointing from current position \(\theta_n\) toward each known minimum. Recomputed at every step.
\[ D(\mathcal{V}, \theta_n) = \left\{ \frac{\theta^*_k - \theta_n}{\|\theta^*_k - \theta_n\|} : \theta^*_k \in \mathcal{V} \right\} \]
03

Hyperparameters

All hyperparameters are tunable. Optimal values vary significantly across domains — a chemistry simulation has very different landscape geometry than a neural network loss surface.

Symbol Name Description
\( \gamma \) Learning rate Step size for both descent and ascent phases
\( \epsilon \) Convergence threshold Gradient norm below which a minimum is declared: \( \|\nabla f(\theta_n)\| < \epsilon \)
\( \delta \) Proximity radius Distance from a known minimum at which trajectory checking activates
\( \alpha \) Trend window scale Scales the trajectory history window proportionally to distance: \( w = \lfloor \alpha \cdot \|\theta_n - \theta^*_k\| \rfloor \). Empirically \( \alpha \approx 0.2\text{–}0.25 \) from geometric reasoning.
\( \tau \) Alignment threshold Dot product value above which the trajectory is considered to be converging toward a known minimum
\( \lambda \) Early stopping threshold Optional. If \( f(\theta^*_k) < \lambda \), terminate immediately. Trades completeness guarantee for speed. Omit for full exhaustive search.
04

Data Structures

Node {
  position: θ*_k // parameter vector of the minimum
  loss: f(θ*_k) // loss value at this minimum
}

PassPoint {
  position: p // parameter vector at the pass
  priority_queue: [v*] // candidate descent directions, sorted descending by distance from V
}

V: Set<Node> // visited minima
P: Stack<PassPoint> // active pass points for backtracking
θ*_best: Node // current best minimum found

// The traversal tree is implicit:
// Nodes = minima in V
// Edges = descents between pass points and minima
// Branches = pass points in P
Implementation note: The priority queue at each pass point orders candidate directions by their distance from all known minima in \(\mathcal{V}\) — farthest first. When a direction is aborted mid-descent, the next direction is popped from the queue automatically.
05

Algorithm — Phase by Phase

Phase 1 — Steepest Descent
\[ \theta_{n+1} = \theta_n - \gamma \nabla f(\theta_n) \]
At every step, for each \( \theta^*_k \in \mathcal{V} \): if \( \|\theta_n - \theta^*_k\| < \delta \), compute trend window:
\[ w = \lfloor \alpha \cdot \|\theta_n - \theta^*_k\| \rfloor \]
Check if trajectory over the last \( w \) steps is converging toward \( \theta^*_k \):
\[ \frac{\theta_n - \theta_{n-w}}{\|\theta_n - \theta_{n-w}\|} \cdot \frac{\theta^*_k - \theta_n}{\|\theta^*_k - \theta_n\|} > \tau \]
If converging → abort descent. See backtracking note below.
If \( \|\nabla f(\theta_n)\| < \epsilon \) without abort → minimum reached.
Record \( \theta^*_k = \theta_n \), add to \( \mathcal{V} \).
If \( f(\theta^*_k) < f(\theta^*_{\text{best}}) \), update \( \theta^*_{\text{best}} \).
If \( \lambda \) is set and \( f(\theta^*_k) < \lambda \), terminate early.
Otherwise → proceed to Phase 2.
Backtracking (default): On abort, return to the most recent pass point in \(\mathcal{P}\) and pop the next best candidate direction from its priority queue. Proceed to Phase 1 from that direction.

Lazy ascent (alternative): On abort, continue ascending from the current position rather than backtracking. Cheaper computationally but geometrically less principled. Recommended for high-dimensional or expensive-to-evaluate landscapes. This is a tunable design choice — make it a flag in implementation.
Phase 2 — Minimum Ascent
Recompute \( D(\mathcal{V}, \theta_n) \) at every step. Ascend via the shallowest valid direction:
\[ \theta_{n+1} = \theta_n + \gamma \cdot \underset{\|v\|=1}{\arg\min} \left[ \nabla f(\theta_n)^\top v \right] \quad \text{subject to} \quad v \notin D(\mathcal{V}, \theta_n) \]
At each ascent step, scan for candidate descent directions — all unit vectors \( v^* \) such that:
\[ \nabla f(\theta_n)^\top v^* < 0 \quad \text{and} \quad v^* \notin D(\mathcal{V}, \theta_n) \]
If one or more \( v^* \) exist → pass point reached.
Store current position as pass point \( p \) in \(\mathcal{P}\).
Build priority queue of all valid \( v^* \), ordered by distance from \(\mathcal{V}\) — farthest first.
Take the best \( v^* \) → proceed to Phase 1.
Phase 3 — Backtracking
Triggered when a pass point's priority queue is exhausted — no valid descent directions remain.
Pop the current pass point from \(\mathcal{P}\). Return to the previous pass point in the stack.
Pop the next best candidate direction from that pass point's priority queue → proceed to Phase 1.
If \(\mathcal{P}\) is entirely empty → proceed to Phase 4.
Phase 4 — Termination
All pass points exhausted. Every reachable descent has been explored or aborted as trending toward \(\mathcal{V}\).
Return \( \theta^*_{\text{best}} \) as the global minimum.

Pseudocode

function MAD(f, θ_init, γ, ε, δ, α, τ, λ=None, lazy=False):
V ← {}                         // visited minima P ← []                         // pass point stack θ_best ← None θ ← θ_init history ← [θ]
loop: // ── PHASE 1: Steepest Descent ── while ‖∇f(θ)‖ ≥ ε: for each θ*_k in V: if ‖θ - θ*_k‖ < δ:   w ← ⌊α · ‖θ - θ*_k‖⌋   if trajectory_converging(history, w, θ*_k, τ):     if lazy: goto PHASE_2     else: goto PHASE_3 θ ← θ - γ · ∇f(θ) history.append(θ)
// minimum reached V.add(θ) if θ_best is None or f(θ) < f(θ_best): θ_best ← θ if λ is not None and f(θ) < λ: return θ_best
PHASE_2: // ── PHASE 2: Minimum Ascent ── while True: D ← exclusion_set(V, θ) candidates ← [v* : ∇f(θ)ᵀv* < 0 and v* ∉ D] if len(candidates) > 0: pq ← priority_queue(candidates, key=dist_from_V(V)) P.push({ position: θ, queue: pq }) θ ← θ + γ · pq.pop_best() break // → back to Phase 1 v_ascend ← argmin_v(∇f(θ)ᵀv, v ∉ D) θ ← θ + γ · v_ascend history.append(θ)
PHASE_3: // ── PHASE 3: Backtrack ── while len(P) > 0: pass_pt ← P.peek() if len(pass_pt.queue) > 0: θ ← pass_pt.position + γ · pass_pt.queue.pop() break // → back to Phase 1 P.pop()
// ── PHASE 4: Terminate ── if len(P) == 0: return θ_best
trajectory_converging(history, w, θ*_k, τ): Returns true if the dot product of the net displacement over the last w steps with the unit vector toward θ*_k exceeds τ. Requires at least w entries in history.
07

Complexity Analysis

Let \( m \) = number of local minima, \( n_d \) = average descent steps per minimum, \( n_a \) = average ascent steps per pass, \( b \) = average branching factor at each pass point, \( d \) = dimensionality, \( |\Theta| \) = total parameter space size.

Case Complexity Condition
Best case \( O(n_d \cdot d) \) Early stopping \(\lambda\) set; first descent lands below threshold
Average case \( O(\log |\Theta| \cdot d) \) Each visited minimum eliminates a neighborhood, pruning large portions of remaining space. Conjectured — to be validated empirically.
Worst case (MAD) \( O(m \cdot (n_d + n_a) \cdot b \cdot d) \) Global minimum is the last found; all minima visited
Worst case (Brute force) \( O(|\Theta| \cdot d) \) Every point in parameter space evaluated
Key insight: MAD worst case is strictly better than brute force since \( m \ll |\Theta| \) in any real landscape. MAD operates only on minima and the paths between them — flat regions, slopes, and ridges are traversed but never exhaustively sampled. Without \(\lambda\), best and worst case are equivalent — MAD always exhausts the full landscape before terminating. The completeness guarantee and inability to stop early are two sides of the same coin.
08

Completeness Guarantee

Theorem (informal): On a finite landscape, MAD is guaranteed to visit every reachable local minimum and return the global minimum, provided \(\lambda\) is not set.

Argument: No minimum is ever revisited (trajectory check + \(\mathcal{V}\) membership). Every pass point exhausts all valid candidate directions before backtracking. The only termination condition is an empty pass point stack, which implies every reachable descent has been explored or correctly aborted. Therefore \(\theta^*_{\text{best}}\) at termination is the global minimum over all reachable minima.
Note on reachability: The tightened dynamic exclusion \( D(\mathcal{V}, \theta_n) \) combined with the backtracking tree ensures that all minima connected via any pass are reachable. Formal proof of universal reachability is left as future work.

Open Problems

# Problem Notes
1 Formal proof of average case \( O(\log |\Theta|) \) Requires assumptions about local minima distribution. To be validated empirically first.
2 Formal proof of universal reachability Conjectured to follow from the backtracking tree structure and dynamic exclusion set.
3 Efficient computation of shallowest ascent direction in high dimensions Constrained argmin over unit sphere excluding \( D(\mathcal{V}, \theta_n) \). May require approximation.
4 Lazy ascent vs backtracking — formal comparison Completeness of lazy variant under what conditions? Currently a tunable flag.
5 Empirical benchmarking vs Adam, SGD, basin hopping Primary validation target. Test on standard benchmark loss landscapes.
